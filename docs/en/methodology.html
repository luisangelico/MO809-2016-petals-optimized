All 5 measured experiments run on bloom-560m — the bloom-1b7 tier exists in the swarm and in the router's model-selection level, but is not the exercised path in the experiments. The models are small enough to run CPU-only on the 3 hosts (no CUDA on this hardware), keeping the Petals pipeline (DHT, block splits, KV cache) faithful to upstream.

Metrics

TTFT (time to first token) · tok/s · router decision time · route composition (spans, precision, nodes) · activation bytes per token · NLL per token vs fp32 reference · token agreement · task accuracy (LAMBADA).
